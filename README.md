# 🍹 Farmhouse Fizz Soda Bar

**Handcrafted Dirty Sodas • Family-run • Built with care**

[Farmhouse Fizz Website](https://farmhousefizz.com)

Farmhouse Fizz Soda Bar is a mobile soda bar based in North Carolina, serving handcrafted Dirty Sodas and specialty non-alcoholic drinks at events, festivals, and private gatherings. This repository contains the source code for the official Farmhouse Fizz website.

The site is designed to be simple, fast, and informative, giving customers an easy way to learn who we are, what we serve, and where to find us next.

---

## 🧑‍🌾 About Farmhouse Fizz

Farmhouse Fizz began in late 2025 as a project between a father and son, built on the idea of creating something meaningful together as a family. Beyond great drinks, the business exists to teach real-world skills like responsibility, teamwork, customer service, and craftsmanship.

We specialize in **Dirty Sodas**, a non-alcoholic drink that originated in Utah. They are made by combining classic sodas with flavored syrups, optional cream, and other mix-ins. It might sound strange at first, but one sip usually changes minds pretty quickly.

---

## 🌐 About the Website

The Farmhouse Fizz website serves as:

- A public-facing homepage for the business  
- An FAQ and educational resource for customers new to Dirty Sodas  
- A place to share event locations, menus, and updates  
- A lightweight, mobile-friendly experience for event-goers  

This repository includes:
- Frontend components and layouts  
- Styling and UI logic  
- Configuration and utility code  

It does **not** include proprietary business data, recipes, branding assets, or internal operations information.

## 🍒 Why Dirty Sodas?

Dirty Sodas let you customize your drink exactly how you want it:

- Choose your soda or sparkling water base  
- Add flavored syrups or fruit  
- Include cream, dairy-free alternatives, or none at all  
- Adjust sweetness to your taste  

It’s soda, just upgraded.
